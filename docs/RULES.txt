Frontend:
- Sử dụng Riverpod để quản lý đối tượng ViewModel, Repository, Service
- Cần export các đối tượng Repository trong frontend/lib/data/providers/repository_providers.dart
- Cần export các đối tượng Service trong frontend/lib/data/providers/service_providers.dart
- Cần tuân thủ nghiêm ngặt MVVM Pattern 
- Khi code, cố gắng decouple các components, tránh phụ thuộc chồng chéo ở cùng một layer.
- Không xóa những comment trong code mà tôi đã tạo
- Nếu code trong một file quá dài (> 600 dòng), nên chia nhỏ ra làm nhiều file
- Với thông báo lỗi/kết quả từ backend, sử dụng widget thông báo nằm trong frontend/lib/ui/core/common/widgets/global_notification.dart

Backend:
- Nếu code trong một file quá dài (> 600 dòng), nên chia nhỏ ra làm nhiều file
- Những công việc giao tiếp với database (sử dụng Prisma) nên được định nghĩa trong src/prisma
